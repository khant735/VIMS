# v0.4.2 Specialist Model Pack
Download All Verified Models installs: full face parsing; EasyPortrait teeth/detail face parsing; SCHP-LIP human parsing; RTMPose whole-body and hand; fingernail segmentation; AP-10K animal pose; Robust Video Matting for fine hair/fur alpha detail.

Direct masks and landmark/matting outputs are intentionally distinguished. Eyelashes, individual teeth, toes/toenails, claws, whiskers and individual fur strands are not falsely presented as native semantic classes where the installed model does not provide them. Open-vocabulary part models (OV-PARTS / PartCATSeg) are tracked as conversion candidates because their published checkpoints are not drop-in ONNX Runtime files.
